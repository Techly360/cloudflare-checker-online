How this Cloudflare checker works

This free Cloudflare detector runs three checks on the domain you enter and combines them into one clear answer.

Cloudflare nameservers

If the domain’s nameservers end in ns.cloudflare.com, its DNS is hosted on Cloudflare.

Cloudflare IP range

If the domain resolves to an IP address owned by Cloudflare, the proxy (orange cloud) is turned on and traffic passes through Cloudflare’s CDN.

Cloudflare HTTP headers

Sites behind Cloudflare usually send a cf-ray header and server: cloudflare in their response.

Frequently asked questions

How do I check if a website uses Cloudflare?

Enter the domain in the box above and click Check domain. The tool looks at the domain’s nameservers, its IP address and the HTTP headers its server returns, then tells you whether Cloudflare is enabled.

How can I tell if Cloudflare proxy (orange cloud) is enabled?

If the domain resolves to a Cloudflare IP range or the response contains a cf-ray header or server: cloudflare, the site is proxied through Cloudflare. If only the nameservers point to Cloudflare, the record is DNS only (grey cloud).

What is the difference between Cloudflare DNS and Cloudflare proxy?

Cloudflare DNS means your domain’s DNS records are hosted at Cloudflare. Cloudflare proxy means visitor traffic also passes through Cloudflare’s network, which adds CDN caching and security features.

Is this Cloudflare checker free?

Yes. The tool is free to use and needs no signup.

Can a site use Cloudflare and still show as not detected?

Rarely. A site can use Cloudflare through a custom setup, such as a partner hosting plan, that hides the usual signals. For nearly all sites the three checks give a reliable answer.
